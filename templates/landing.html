Drag-and-drop upload

Drop a CSV, XLSX or XLS file up to 16 MB. Columns, data types and a row preview appear straight away, with a per-column overview so you can spot gaps before you chart.

Clean columns first

Rename messy headers or drop columns you don't need. Dropped columns stay out of every future chart built from that dataset.

11 chart types

Bar, line, pie, scatter, horizontal bar, area, doughnut, radar, stacked bar, combo and histogram. Switch type without re-uploading.

Make it look right

The Customise panel covers titles, legend position, axis titles, gridlines, font size, your own series colours and smooth or straight lines.

Save, search, edit

Every chart lives in My Charts. Search by title, sort by date, and reopen any chart later to change columns, type or colours.

Reports

Bundle several saved charts into one report behind a single shareable link. Good for a weekly summary or a client update.

Boards

Arrange charts in one grid with small, medium or large tiles. Refresh on demand or on a timer, then download the board as PNG or PDF.

Live Charts

Stream data into a line, bar, scatter or gauge view from simulated data, one of your datasets or an API endpoint that returns JSON.

Share and embed

One public link per chart, report or board. Unshare any time, embed charts and reports with an iframe, and export charts as PNG or PDF.

Before you start

What file types can I upload?

CSV and Excel (.xlsx, .xls), up to 16 MB.

Can I edit a chart after saving it?

Yes. Open it from My Charts and hit Edit to change the columns, chart type, colour scheme or any Customise option.

What do people see when I share something?

Only the charts themselves, built from the summarised data each chart needs. Viewers never get your raw rows or the uploaded file, and they can't change anything.

What's the difference between a chart, a report and a board?

A chart is one visualisation. A report bundles several saved charts behind one link. A board puts saved charts in one grid with tile sizes you choose, and it can refresh itself.
